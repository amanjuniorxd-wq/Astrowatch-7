# Astrowatch dependency list.

# pyswisseph is now a REQUIRED, load-bearing dependency (not optional) as of the
# Swiss Ephemeris migration -- astrowatch/kundli.py imports it at module load time

# files (astrowatch/ephemeris/) aren't present. See

# the full setup/rationale.
#
# Everything else in the project still uses only the Python standard library
# (urllib, math, dataclasses, unittest, sqlite3, argparse, re, zoneinfo, http.server).
# The chart API (astrowatch/api.py) deliberately uses http.server rather than adding
# a web-framework dependency (Flask/FastAPI/etc.) -- see api.py's own docstring.
